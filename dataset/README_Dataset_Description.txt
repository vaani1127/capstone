HealthSaathi Capstone Dataset Package

Dataset Source:
This package uses the Synthea synthetic healthcare dataset. Synthea generates realistic but fake patient records, so it is safe for academic use and does not expose real patient information.

Folder Structure:
1. main_dataset
   Contains the required dataset files for the main HealthSaathi modules.

2. optional_dataset
   Contains extra files that are useful only if the project includes vaccination or billing/insurance modules.

3. documentation
   Contains this explanation and a dataset summary file.

Main Dataset Files:
01_patients.csv
- Used for patient management.
- Contains patient demographic and basic healthcare profile information.

02_appointments_encounters.csv
- Used for appointments, visits, and OPD encounter history.
- This is mapped from Synthea encounters.csv.

03_diagnoses_conditions.csv
- Used for diagnosis and medical condition history.
- This is mapped from Synthea conditions.csv.

04_prescriptions_medications.csv
- Used for prescription and medicine records.
- This is mapped from Synthea medications.csv.

05_vitals_observations.csv
- Used for vitals, lab values, and clinical observations.
- This is mapped from Synthea observations.csv.

06_allergies.csv
- Used for storing patient allergy records.

07_procedures.csv
- Used for medical procedures performed during treatment.

08_organizations.csv
- Used for clinic, hospital, or healthcare organization details.

09_audit_logs_synthetic.csv
- Generated synthetic access-log dataset for anomaly detection.
- This file is added because public real hospital access logs are usually not available due to patient privacy and security restrictions.
- It contains role, action, timestamp, patient access, off-hours flag, actions per hour, untreated patient ratio, and anomaly label.

Optional Dataset Files:
09_optional_immunizations.csv
- Optional addition.
- Reason: Include this only if HealthSaathi includes a vaccination or immunization history module.
- It is not required for the core HMS, appointment, prescription, or anomaly detection flow.

10_optional_claims.csv
- Optional addition.
- Reason: Include this only if HealthSaathi includes billing, insurance, or claim analysis features.
- It is not required for the core clinical workflow.
- It can be useful later if the project expands toward healthcare finance or insurance fraud analysis.

Recommended Teacher Explanation:
The HealthSaathi project uses a synthetic healthcare dataset generated by Synthea. The main dataset contains patient records, appointments, diagnoses, prescriptions, observations, allergies, procedures, and organization details. Immunizations and claims are included separately as optional datasets because vaccination and billing/insurance features are not required for the core system but can be added as future modules. A synthetic audit-log dataset is also included for anomaly detection because real hospital access logs are not publicly available due to privacy and security concerns.

Suggested Presentation Order:
1. Show main_dataset folder.
2. Open 01_patients.csv, 02_appointments_encounters.csv, 03_diagnoses_conditions.csv, 04_prescriptions_medications.csv, and 05_vitals_observations.csv.
3. Show 09_audit_logs_synthetic.csv for the anomaly detection module.
4. Explain optional_dataset separately:
   - immunizations = optional vaccination module
   - claims = optional billing/insurance module
